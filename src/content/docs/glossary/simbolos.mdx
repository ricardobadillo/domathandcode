---
title: Símbolos y notación
description: Símbolos y notación matemática de uso habitual en todas las materias
---

### Lógica:

| Símbolo | Significado |
| :---: | :--- |
| $$\neg p$$ | negación de $$p$$ («no $$p$$») |
| $$p \wedge q$$ | conjunción («$$p$$ y $$q$$») |
| $$p \vee q$$ | disyunción («$$p$$ o $$q$$») |
| $$p \to q$$ | implicación («si $$p$$, entonces $$q$$») |
| $$p \leftrightarrow q$$ | bicondicional («$$p$$ si y sólo si $$q$$») |
| $$\forall$$ | cuantificador universal («para todo») |
| $$\exists$$ | cuantificador existencial («existe») |
| $$\exists!$$ | «existe un único» |
| $$\therefore$$ | «por tanto» |
| $$\because$$ | «porque» |

### Conjuntos:

| Símbolo | Significado |
| :---: | :--- |
| $$a \in A$$ | $$a$$ pertenece a $$A$$ |
| $$a \notin A$$ | $$a$$ no pertenece a $$A$$ |
| $$A \subseteq B$$ | $$A$$ es subconjunto de $$B$$ |
| $$A \subsetneq B$$ | subconjunto propio |
| $$A \cup B$$ | unión |
| $$A \cap B$$ | intersección |
| $$A \setminus B$$ | diferencia |
| $$\varnothing$$ | conjunto vacío |
| $$\mathcal{P}(A)$$ | conjunto potencia |
| $$\lvert A \rvert$$ | cardinal (número de elementos) |
| $$\{x : P(x)\}$$ | conjunto por comprensión (tal que) |

### Conjuntos numéricos:

| Símbolo | Significado |
| :---: | :--- |
| $$\mathbb{N}$$ | números naturales |
| $$\mathbb{Z}$$ | números enteros |
| $$\mathbb{Q}$$ | números racionales |
| $$\mathbb{R}$$ | números reales |
| $$\mathbb{C}$$ | números complejos |
| $$\mathbb{P}$$ | números primos |

Se cumple la cadena de inclusiones $$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$$.

### Comparación y relaciones:

| Símbolo | Significado |
| :---: | :--- |
| $$=$$ | igualdad |
| $$\neq$$ | distinto |
| $$\approx$$ | aproximadamente igual |
| $$<,\ \leq,\ >,\ \geq$$ | menor, menor o igual, mayor, mayor o igual |
| $$\equiv$$ | congruente o idénticamente igual |
| $$\sim$$ | equivalente o del mismo orden |
| $$\propto$$ | proporcional a |

### Operaciones y cálculo:

| Símbolo | Significado |
| :---: | :--- |
| $$\sum$$ | sumatoria |
| $$\prod$$ | productoria |
| $$\sqrt{\ },\ \sqrt[3]{\ }$$ | raíz cuadrada, cúbica |
| $$\lvert x \rvert$$ | valor absoluto |
| $$n!$$ | factorial de $$n$$ |
| $$\binom{n}{k}$$ | coeficiente binomial |
| $$\pm,\ \mp$$ | más/menos, menos/más |
| $$\infty$$ | infinito |
| $$\lim_{x \to a}$$ | límite cuando $$x$$ tiende a $$a$$ |
| $$f'(x),\ \dfrac{df}{dx}$$ | derivada |
| $$\dfrac{\partial f}{\partial x}$$ | derivada parcial |
| $$\nabla f$$ | gradiente |
| $$\int,\ \iint,\ \iiint$$ | integral simple, doble, triple |
| $$\Delta x,\ \delta$$ | incremento, incremento pequeño |

### Vectores y geometría:

| Símbolo | Significado |
| :---: | :--- |
| $$\vec{v}$$ | vector |
| $$\lVert \vec{v} \rVert$$ | norma (módulo) de un vector |
| $$\vec{u} \cdot \vec{v}$$ | producto escalar |
| $$\vec{u} \times \vec{v}$$ | producto vectorial |
| $$\angle ABC$$ | ángulo |
| $${}^\circ$$ | grados sexagesimales |
| $$\pi$$ | número pi, $$\pi \approx 3{,}14159$$ |

### Varios:

- $$\Rightarrow$$ y $$\Leftrightarrow$$ son las versiones «gruesas» de $$\to$$ y $$\leftrightarrow$$.
- $$\lvert x \rvert$$ también se escribe $$\operatorname{abs}(x)$$ en programación.
- En código, la multiplicación se escribe `*`, la potencia `**` o `^` según el lenguaje, y la división `/`.
